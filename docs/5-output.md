# 5. Output

[Overview](../README.md#overview) · Previous [Flattening & capture](4-flattening-and-capture.md) · [Sensors & control](sensors-and-control.md)

After the final capture, transport releases the strip into a collection area. The exit geometry and collection method are open.

| Proposed concept                | Trade-off to test                                                                                                                    |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Passive tray after belt release | Few moving parts. The exit must clear both single frames and curled strips without abrasion or a pile backing up into the path.      |
| Driven exit into a tray         | Adds control of the release point. Adds another grip and raises the question of contact pressure and synchronization with the belts. |

## Open questions and experiments

- Side-view mock-ups should show where the shortest strip loses belt grip, where it lands, and how the last strip in a batch clears the accumulated pile.
- Compare both exits with mixed test strips. Check for scratches, hang-ups and retained pieces before feeding the next strip.
